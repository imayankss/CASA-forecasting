# Archived reports

`BOI_CASA_Forecasting_Report_v2.docx` is kept for the record only. Do not rely on it:

- **It uses synthetic data.** The deposit series and macro indicators were generated with an LLM (see [`data/raw/README.md`](../../data/raw/README.md)). The report describes the macro data as "historically accurate", which was never checked.
- **Its numbers don't match the code.** For example, it reports a Holt-Winters R² of 0.892, 5-fold cross-validation, and R² above 0.60 for all six models. The pipeline in this repository produces R² 0.806 for Holt-Winters, negative R² for four models, and 3 cross-validation folds (`data/processed/model_leaderboard.csv`, `data/processed/cv_summary.csv`).

The reports in `reports/` generated by `run_reports.py` are the source of truth.
